Emergency Purge

How to play: Use your arrow keys to move the tiles. When two tiles with the same number touch, they merge into one with double the value! In a nutshell, the goal is to get the 2048 tile.

The Emergency Purge button allows you to purge all tiles with a value of 2 and 4, if the board is filled (no empty spaces). Sometimes it can be difficult to not make a wrong move when the board is filled. This is because it is easy to get in a situation where there are no possible moves and the game ends. The Emergency Purge feature was added to make it easier to get through situations like this.
